🎯 ساختار کلی سیستم

💡 دو بخش اصلی:

  • UMD (پایه): شامل اطلاعات کارمندان، گروه‌ها، پروژه‌ها و موقعیت‌های شغلی
  • Timesheet (برنامه): شامل ثبت ساعات کاری، گزارش‌ها، هزینه‌ها و تنظیمات

🔄 جریان کار سیستم

1️⃣ ثبت اطلاعات پایه → کارمندان، گروه‌ها، پروژه‌ها
2️⃣ تعریف قراردادها → ساعات کاری، دسترسی‌ها
3️⃣ ثبت روزانه → ورود/خروج، وظایف، هزینه‌ها
4️⃣ گزارش ماهیانه → تایید مدیر، امور مالی

🔗 روابط بین جداول

👤 کارمندان و اطلاعات پایه
Users → Groups (از طریق GroupId)
Users → UserPositions (از طریق UserId)
Groups → Users (مدیر از طریق ManagerId)
📋 قراردادها و دسترسی‌ها
Users → UserContractHours (قرارداد کاری)
Users → UserProjectAccess ← Projects
📅 فعالیت‌های روزانه
Users → DailyDetails (حضور و غیاب روزانه)
Users + Projects → DailyProjectTasks (وظایف روزانه)
Users + Projects → DailyPersonalCarCosts (هزینه ماشین)
📊 گزارش‌های ماهیانه
Users → MonthlyReports (گزارش ماهیانه)
Users → MonthlyGymCosts (هزینه ورزش)

✅ نکات مهم روابط:

  • همه جداول Timesheet به جدول Users متصل هستند
  • جدول DailyProjectTasks به هر دو Users و Projects وابسته است
  • جدول MonthlyReports به Groups نیز متصل است (برای تایید مدیر)
  • تمام روابط از طریق Foreign Key پیاده‌سازی نمی‌شوند (انعطاف بیشتر)

🚀 راهنمای استفاده ساده

📝 مراحل راه‌اندازی:

  1. دیتابیس UMD را بسازید (اگر ندارید)
  2. جداول پایه را ایجاد کنید با اجرای 01-create-umd-base-tables.sql
  3. جداول Timesheet را بسازید با اجرای 02-create-app-tables.sql
  4. داده‌های تستی پایه را وارد کنید: 03 و 04
  5. فایل‌های ساده (کوچک) را اجرا کنید که در ادامه توضیح داده می‌شود

✨ فایل‌های ساده برای اجرا:

به جای فایل‌های بزرگ، از فایل‌های کوچک زیر استفاده کنید:

  • simple-contracts.sql: قراردادهای کاری ساده
  • simple-access.sql: دسترسی‌های پروژه
  • simple-daily.sql: چند روز نمونه
  • simple-monthly.sql: یک گزارش ماهیانه

👉 این فایل‌ها در ادامه ایجاد می‌شوند...
