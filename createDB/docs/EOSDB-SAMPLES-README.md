## 🚀 نحوه استفاده

### روش 1: اجرای به ترتیب
```bash
# 1. داده‌های پایه
sqlcmd -S localhost -d EOSDB -i 13-insert-advanced-test-data.sql

# 2. سناریوهای پیچیده
sqlcmd -S localhost -d EOSDB -i 14-insert-complex-scenarios.sql

# 3. تست کوئری‌ها
sqlcmd -S localhost -d EOSDB -i 15-sample-queries.sql
```

### روش 2: از SQL Server Management Studio
1. باز کردن SSMS
2. اتصال به EOSDB
3. اجرای فایل‌ها به ترتیب

### روش 3: استفاده انتخابی
می‌توانید فقط بخش‌های خاصی از هر فایل را اجرا کنید.
