### README.md

این مخزن شامل یک API بک‌اند برای یک اپلیکیشن تایم‌شیت (timesheet) است که با استفاده از Node.js، Express و پایگاه داده MSSQL ساخته شده است. این API مدیریت پروژه‌ها، جزئیات روزانه و وظایف مرتبط را پشتیبانی می‌کند.

-----

### ویژگی‌ها

* **مدیریت پروژه‌ها**: امکان ایجاد، خواندن (تک و همه)، به‌روزرسانی و حذف پروژه‌ها.
* **مدیریت جزئیات روزانه**: امکان ایجاد یا به‌روزرسانی جزئیات روزانه برای یک کاربر در یک تاریخ خاص. این جزئیات شامل زمان ورود/خروج، نوع مرخصی، زمان شخصی و هزینه‌ها می‌شود.
* **مدیریت وظایف**: ذخیره‌سازی وظایف روزانه مرتبط با پروژه‌ها.
* **مدیریت هزینه‌ها**: ثبت هزینه‌های شخصی خودرو برای هر روز و پروژه.
* **API مستندسازی شده**: مستندات Swagger برای تمامی endpointها در دسترس است.
* **اتصال به MSSQL**: از کتابخانه `mssql` برای اتصال به پایگاه داده MSSQL استفاده می‌کند.
* **متغیرهای محیطی**: پیکربندی اتصال به پایگاه داده از طریق فایل `.env` انجام می‌شود که امنیت اطلاعات حساس را تضمین می‌کند.

-----

### فناوری‌های استفاده شده

این پروژه از فناوری‌های زیر استفاده می‌کند:

* **Node.js**
* **Express.js**: فریم‌ورک وب برای ساخت API.
* **MSSQL**: درایور برای اتصال به پایگاه داده Microsoft SQL Server.
* **Swagger-UI-Express & Swagger-JSDoc**: برای تولید و نمایش مستندات API.
* **Luxon**: کتابخانه برای مدیریت تاریخ و زمان.
* **Dotenv**: برای مدیریت متغیرهای محیطی.
* **CORS**: برای فعال‌سازی Cross-Origin Resource Sharing.

### راه‌اندازی پروژه

#### پیش‌نیازها

مطمئن شوید که موارد زیر روی سیستم شما نصب شده‌اند:

* Node.js (نسخه ۱۸ یا بالاتر)
* Microsoft SQL Server

#### ۱. نصب وابستگی‌ها

ابتدا، وارد پوشه پروژه شوید و وابستگی‌های مورد نیاز را نصب کنید:

```sh
npm install
```

#### ۲. پیکربندی پایگاه داده

فایل `.env` را در ریشه پروژه ایجاد کنید و اطلاعات اتصال به پایگاه داده خود را در آن قرار دهید:

```ini
DB_USER=sa
DB_PASSWORD=123@asd
DB_SERVER=localhost
DB_DATABASE=flutter
DB_PORT=1433
```

**توجه**: این فایل حاوی اطلاعات حساس است و نباید در یک مخزن عمومی Git قرار گیرد. به همین دلیل در فایل `.gitignore` ذکر شده است.

#### ۳. ایجاد جداول پایگاه داده

اسکریپت SQL موجود در فایل `createTable.txt` را اجرا کنید تا تمامی جداول مورد نیاز (شامل `Projects`, `Users`, `DailyDetails`, `DailyProjectTasks`, `DailyPersonalCarCosts`, `Holidays`, و `UserContractHours`) و داده‌های نمونه اولیه ایجاد شوند.

#### ۴. اجرای برنامه

با استفاده از nodemon، برنامه را اجرا کنید:

```sh
npm run dev
```

سرور در آدرس `http://localhost:3000` اجرا خواهد شد.

### مستندات API

مستندات کامل API با استفاده از Swagger در دسترس است. پس از اجرای سرور، می‌توانید به آدرس زیر مراجعه کنید:

`http://localhost:3000/api-docs`

این مستندات شامل جزئیات تمامی endpointsها و مدل‌های داده‌ای مورد استفاده است.

### مسیرهای API

* `GET /projects`: دریافت لیست تمامی پروژه‌ها.
* `GET /projects/{id}`: دریافت یک پروژه خاص بر اساس شناسه.
* `POST /projects`: ایجاد یک پروژه جدید.
* `PUT /projects/{id}`: به‌روزرسانی یک پروژه موجود.
* `DELETE /projects/{id}`: حذف یک پروژه.
* `GET /daily-details/{date}?userId={userId}`: دریافت جزئیات روزانه برای یک تاریخ و کاربر مشخص.
* `GET /daily-details/range?startDate={startDate}&endDate={endDate}&userId={userId}`: دریافت جزئیات روزانه برای یک بازه زمانی.
* `POST /daily-details`: ایجاد یا به‌روزرسانی جزئیات روزانه.
* `GET /daily-details/month/{year}/{month}?userId={userId}`: دریافت جزئیات ماهانه برای یک سال و ماه مشخص.
